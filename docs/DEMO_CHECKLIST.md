# 주유로 시연 체크리스트

Pleos Connect 에뮬레이터에서 **정차 상태**로 진행하는 시연을 위한 체크리스트입니다. 실제 검증 결과는 [검증 문서](TESTING.md)를 참고합니다.

## 시연 전 준비

- [ ] Pleos Connect 에뮬레이터와 제출할 APK를 준비하고 앱을 실행한다. 개발 기준 환경은 Pleos Connect 2.1.0 / Android 14, Connect-S-17이다.
- [ ] 네트워크와 현재 위치를 확인하고, 차량 에너지 접근 권한을 요청하면 허용한다.
- [ ] 주유소 검색 결과가 나오는 위치인지 미리 확인한다. 검색 결과와 가격은 위치·시점에 따라 달라질 수 있다.
- [ ] 시스템 내비게이션의 현재 목적지와 경유지를 확인한다. 시연 후 원래 경로로 돌아갈 수 있도록 기록한다.
- [ ] 경유 비용 추정을 보여줄 계획이라면 카카오 API 키가 설정된 빌드에서 미리 조회 가능 여부를 확인한다. debug·release·qaRelease 모두 키가 있을 때 제공한다.

## 주유 조건 확인

현재 개발 에뮬레이터에는 내연기관 차량 모드가 없어 검색 유종과 예상 주유량을 직접 설정하고, 연비를 가져오지 못하면 수동값을 사용한다. 에너지원이 전기로 표시될 수 있으며, 이는 전기차 충전 비교를 의미하지 않는다.

- [ ] 홈에서 주유 조건을 열고 검색 유종을 선택한다.
- [ ] 예상 주유량을 10~100L 범위에서 설정한다. 예: 40L. 차량 잔량으로 자동 대체되지 않는다.
- [ ] 수동 평균연비를 확인한다. 예: 12km/L. 차량 누적 연비 조회에 성공하면 계산에는 조회값이 우선 적용되며, 수동 평균연비는 계속 편집할 수 있다.
- [ ] 주유 시간을 확인한다. 검색 반경은 3km 고정이며 시간 비용 옵션은 없다. 변경은 즉시 저장되고 다음 검색에 사용되며 앱 재시작 후에도 복원된다.

## 기본 시연: 주유소 비교와 목적지 설정

- [ ] 목적지가 없는 상태에서 **주변 주유소 찾기**를 누른다.
- [ ] 검색 결과에서 주유소별 가격과 도착 시간, 선택한 주유소의 거리·비용 내역을 보여준다. 조회가 진행 중이면 기준 유가와 순절약액이 달라질 수 있음을 설명하고 결과 갱신을 기다린다. 잠정값 안내 문구는 화면에 표시되지 않는다.
- [ ] 다른 후보를 선택하고 **절약액순 / 시간순** 정렬을 바꾸어 비교한다.
- [ ] 순절약액은 검색 결과에서 경로를 확보한 후보 중 최고가를 기준으로 한 **주유소까지 편도 추정치**이며 통행료는 제외된다고 설명한다.
- [ ] 선택한 주유소를 **목적지로 설정**하고 완료 화면에서 **내비게이션 열기**를 선택한다. 실제 내비에서 반영 결과를 확인한다.

## 선택 시연: 기존 목적지에 경유지 추가

- [ ] 시스템 내비게이션에 목적지를 설정하고 기존 경유지가 없는지 확인한다.
- [ ] 앱에서 다시 검색하고 주유소를 선택한다.
- [ ] 경유 추정이 표시되면 추가 거리·추가 주행 시간·주유 포함 추가 시간·경유 순절약액을 확인한다. 통행료 차이는 경유 순절약액에 반영되지만 별도로 표시되지 않는다. 이 값은 별도 카카오 경로 추정이며 편도 목록 순위에 반영되지 않는다.
- [ ] **경유지로 추가**를 선택하고, 내비게이션에서 주유소가 경유지로 추가되고 기존 목적지가 유지되는지 확인한다.

## 시연 후 확인

- [ ] 필요하면 시연 전의 내비게이션 목적지와 경유지 상태로 되돌리고 확인한다.
- [ ] 결과가 없거나 경로 조회에 실패하면 현재 위치·네트워크와 고정 반경 3km 안에 후보가 있는지 확인한 뒤 다시 검색한다. 미조회 또는 실패한 후보의 수치를 임의로 설명하지 않는다.
- [ ] 제출 APK의 빌드 유형과 실제 지원 기능이 README 및 시연 내용과 일치하는지 확인한다.

실차 동작과 주행 중 사용 적합성은 이 체크리스트의 검증 범위가 아니다.
