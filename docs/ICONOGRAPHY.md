# 아이콘 지침

기준은 [Pleos Iconography](../pleos_sdk_guide/앱%20기획·설계%20가이드/디자인%20가이드/Foundations/Iconography.md)다.
`core:design/component/PleosIcons.kt`에서 이번 프로토타입에 필요한 outlined 벡터를 공유한다. 외부 라이브러리 에셋을 복제하지 않은 프로젝트
자체 제작 기하 도형이며, 별도 제3자 라이선스는 없다. Pleos 공식 아이콘 에셋은 아니다. 기본 크기는 48dp이며 사용 위치에 따라 비율을 유지해 조정한다. 뒤로·다음
화살표는 RTL에서 반전한다.

## Pleos 제작 원칙

- 누구나 의미를 직관적으로 인지할 수 있는 형태를 사용한다.
- 기본 `48 × 48dp` 그리드를 기준으로 제작한다. 상세 그리드와 형태는 원문 문서의 도해를 참조한다.
- 시인성과 사용 상황에 따라 Filled 또는 Outlined 스타일을 선택한다.
- 한 벌의 원본을 제작한 뒤 필요한 크기로 조정해 사용한다. 추가 크기 단계나 획 두께는 원문의 도해와 해당 컴포넌트 규격을 확인하고, 확인되지 않은 수치를 Pleos 공식 토큰으로 만들지 않는다.

## 프로젝트 적용 지침

아래는 원문을 앱에 적용하기 위한 프로젝트 지침이다.

- 동일한 기능에는 같은 아이콘을 사용하고, 한 화면에서 같은 역할의 아이콘은 스타일과 시각적 크기를 일관되게 유지한다.
- 아이콘을 축소·확대할 때 가로세로 비율을 유지하고, 좁은 분할 창에서도 의미를 알아볼 수 있는지 확인한다. 48dp는 제작 그리드이며 터치 영역 규격을 뜻하지 않는다. 터치 영역은 해당 Pleos 컴포넌트 가이드를 따른다.
- 아이콘 색상은 `JUYULOWTheme.colors.iconDarkPrimary` 등 기존 역할별 색상 토큰을 사용한다. 라이트·다크 모드에 따라 원색을 직접 지정하거나 임의로 반전하지 않는다. `iconLight*`는 반대 명도의 배경 위에 사용할 때 선택한다.
- 의미를 가진 조작 아이콘에는 동작을 설명하는 접근성 레이블을 제공한다. 인접 텍스트가 같은 의미를 전달하는 장식 아이콘은 중복 낭독을 피한다. 선택·비활성 상태는 색상만으로 전달하지 않는다.
- 실제 에셋을 추가할 때는 `core:design`에서 공유하고 출처와 사용 조건을 기록한다. Material 아이콘 등 외부 에셋을 사용해도 Pleos 공식 아이콘과 동일하다고 간주하지 않는다.
- 새 화면의 아이콘은 가로형 `1700 × 1184dp`, 세로형 `840 × 1184dp`에서 확인하고, 작은 모델 대응 시 [Display Layout](../pleos_sdk_guide/앱%20기획·설계%20가이드/디자인%20가이드/Getting%20Started/Display%20Layout.md)의 앱 영역도 확인한다.
