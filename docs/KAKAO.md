# 카카오 경유 추정 (개발·시연용)

공식 계약: https://developers.kakaomobility.com/guide/navi-api/directions

- local.properties의 KAKAO_REST_API_KEY를 debug BuildConfig로 공급한다. 키·인증 헤더·응답 원문은 로그에 남기지 않는다.
  release는 빈 키로 생성하고 저장소를 주입하지 않는다. APK의 키는 비밀 저장소가 아니다.
- GET /v1/directions, Authorization: KakaoAK, WGS84 경도,위도 순서. summary=true, alternatives=false. 성공
  result_code와 필수 m·초·통행료 원 값을 검증한다.
- 검색 시작 위치 A와 목적지 B를 고정해 기준 A→B 1회 후 최대 15개 A→S→B를 동시 2건으로 조회한다. 시도당 연결 10초·전체 30초 제한이며 요청 실패 시
  0.5초·1초 간격으로 최대 2회 재시도한다 (총 최대 3회). 재시도 포함 검색당 HTTP 호출은 최대 48회다. 세션
  메모리 외 캐시 없음.
- 재시도 소진 후 기준 실패는 경유 요청을 생략하고 인증/403/429는 남은 작업을 중단한다. 취소와 키 누락·입력 검증 실패는 재시도하지 않는다. HTTP 취소는 SDK
  Trip 취소와 별개다. 실패값을 0원으로 대체하지 않는다.
- HTTP·네트워크·타임아웃·경로 결과 오류·잘못된 응답이 재시도 대상이다. 기준 경로와 각 후보 경유 요청의 재시도 횟수는 각각 독립적이다.
- 차이는 동일 공급자·옵션 결과끼리 계산하며 음수를 보존한다. 주유시간은 소요시간에 더하며 시간 비용은 차감하지 않는다. Pleos 편도 수치와 차감하지 않는다. 카카오 폴리라인·장소 검색을
  사용하지 않고 실제 경로 설정은 Pleos가 담당한다.
- RECOMMENDED/SHORT_TIME/SHORT_DISTANCE/FREE를 추천/시간/거리/유료도로 회피로 매핑한다. 그 밖은 추천 가정을 표시한다. AAOS 실제 연료
  코드로 확실한 휘발유·경유·LPG만 매핑하고 비교 검색 유종으로 추정하지 않는다. 차량 세부 등급·하이패스는 미확보여서 차종 1·미장착을 가정한다.
- 목적지·경유지·옵션 변경 또는 50m 초과 이동 시 화면에서 만료를 표시한다. 경유 추정 가용성과 Pleos 실제 경유 추가 지원은 별개다.
- 2026-11-12 공식 예시 좌표로 기준·경유 각 1회 실호출: HTTP 200, result_code 0. 기준 1991m/423초/0원, 경유
  19922m/3512초/0원. 시각별 교통 상태로 수치는 달라진다.

공개 배포용 프록시·정책·위치 전송 고지 검토는 BACKLOG.md에서 관리한다.
